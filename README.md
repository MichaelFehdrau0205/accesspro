# Access Pro

Your access needs, ready on the spot.

Access Pro lets a person set up their access needs once, then use them anywhere. It stops disabled New Yorkers from re-explaining and re-fighting for access every single time.

## How it works

1. Set a profile once: ASL interpreter, captions, visual alerts, wheelchair access, plain language, quiet space.
2. Pick the situation: doctor, housing office, court, job interview, event, 911, or transit.
3. Get a ready-to-send request written for that setting.
4. Get a big, high-contrast access card to show staff on a phone.

The access card is the demo moment. Example: “I’m Deaf. Please use written notes or text. I need an ASL interpreter.”

Free for individuals. Clinics, agencies, and employers pay to receive structured requests and track compliance.

## Hackathon scope

In scope for the first build:

- Profile checkboxes, saved locally, no login
- Four situations
- One AI call that writes the request and the card text
- Full-screen show-to-staff mode

Cut if time runs short: accounts, history, maps, multiple languages.
